# MockPad — Shaping

更新日: 2026-10-24（日本時間）

## Source

ユーザーの決定を抜粋。引用は原文。

> 私が面接官をする模擬面接で使用する予定です。
> 「面接官が部屋を作る → URLを共有 → 通話しながらコードを書く → 講評する」という流れを考えています。

> 言語とタブサイズは部屋全体で共有したいです。
> 編集するコードはURL一つにつき1つで十分です。
> ログインは不要です。

> 部屋の作成・終了については、上記でお願いします。

> 全員が不在になってからの保存時間は24時間でお願いします。

> サーバー再起動後はコードを保持しなくてよいです。

## 問題と成果

面接官であるユーザーと受験者が、同じコードを見て、位置を指し示しながら編集できる場を用意する。
URLを共有すれば利用でき、実行環境の準備やアカウント作成を求めない。
音声通話と講評はDiscordで行う。MockPad内に通話、チャット、面接履歴、フィードバック保存を追加しない。

## A: Rustのメモリー上で保持する共同編集ルーム

採用する設計。ブラウザーはTypeScriptで実装し、サーバー側をRustにする。
サーバーは単一プロセスで動かし、データベースとディスクへのコード保存を設けない。

| Part | 仕組み | 根拠・検証 |
|---|---|---|
| A1 | 部屋作成APIがランダムな部屋IDと管理用シークレットを発行。シークレットは作成ブラウザーのHttpOnly・SameSite Cookieに保存し、参加URLには含めない。部屋IDから参加し、表示名を入力する | V1/V4実装済み。E2Eで作成・共有・入室・終了権限を確認 |
| A2 | Monaco Editorのモデルと部屋のY.Textをy-monacoで接続する。Yjsの更新をWebSocketでRustのYrsへ送り、適用した更新を参加者へ配信する。初回接続・再接続時はstate vectorを交換して不足分を同期する | V1/V3実装済み。実WebSocketで同時編集・再同期・日本語・絵文字を確認 |
| A3 | 言語とタブサイズをY.Mapに置き、変更通知から両者のMonacoへ適用する。insertSpacesを有効、detectIndentationを無効にして共有設定を優先する。改行はMonacoの言語別autoIndent、Tabはインデント幅に従う | V2実装済み。設定共有とJavaScript/Python/RustのEnter/Tabを確認 |
| A4 | Yjs Awarenessで表示名・色・相対選択位置を配信。y-monacoの選択範囲デコレーションに色と名前ラベルの表示を追加する。WebSocket切断時はその接続の参加者情報を除去する | V2実装済み。Rust経由の配信、名前ラベルと選択表示をE2E・実画面で確認 |
| A5 | Y.UndoManagerの対象をコードのY.Text、trackedOriginsを自分のMonacoBindingに限定する。モデルのundo/redo、ボタン、キーバインド、右クリックアクションをこのUndoManagerへ接続する | V2実装済み。ボタン・Ctrl+Z/Ctrl+Shift+Z・右クリックをE2E確認、Ctrl+Yはスパイクで確認 |
| A6 | クライアントの状態を接続中・同期中・接続済み・再接続中・終了に分ける。切断中と初回同期前は編集を無効化し、既に発生した未送信更新はタブ内で維持する。再接続後に不足分を同期し、同期完了後に編集を再開する | V3実装済み。接続遮断後の自動再接続、編集不可、復帰後の同期をE2E確認 |
| A7 | Rustの部屋レジストリーがYrs文書・管理シークレット・接続一覧・全員不在の開始時刻を保持。終了APIは管理権限を確認する。終了または期限切れで更新受付を止め、レジストリーから除去して接続を閉じ、メモリーを解放する | V4実装済み。Rustの5テストとE2Eで期限・権限・終了・再起動を確認 |

### 確定した振る舞いと設計上の初期値

- 面接官・受験者ともコード、言語、タブサイズを変更できる。部屋の終了だけ面接官に限定する。
- 共有URLには管理シークレットを含めない。同じブラウザープロファイルなら再読み込み後も管理Cookieで面接官と判定する。別ブラウザーへの管理権限移譲・紛失時の復旧は初版に含めない。
- 初期言語はプレーンテキスト、初期タブサイズは4。タブサイズは2/4/8から選ぶ。これは要件追加ではなく、変更可能な初期値としての設計判断。
- 言語選択にはMonacoに登録した組み込み言語を使う。基本のハイライトとインデントを提供し、独自の言語解析サービスは追加しない。
- 参加者名と色はAwarenessの状態。名前は表示上の識別であり、管理権限の判定には使わない。色はアプリの固定パレットから割り当てる。
- Undo履歴はブラウザーのタブ内のみ。コードや共有設定をブラウザーストレージへ保存しない。再読み込みでUndo履歴は失われるが、存続中の部屋のコードは再取得できる。
- 部屋の不在時間は接続数が0になった時点から数える。未入室の部屋は作成時点から数える。入室時に不在タイマーを解除し、最後の退出時に新しく起算する。キー入力の有無は判定に使わない。
- 接続切断はWebSocketのcloseとheartbeatのタイムアウトで検出する。検出後の最終接続除去時に不在時刻を設定する。
- 不在から24時間以上経った部屋は、定期清掃を待たず、入室APIとWebSocket受付でも期限切れと判定する。期限切れの部屋へのアクセスで猶予を延長しない。
- 終了・期限切れ・再起動後の古いURLでは部屋を再作成しない。既存接続も削除済み文書へ更新を適用しない。
- 終了操作は確認画面を挟む。成功後はコードを画面から取り除き、再接続を停止する。
- 新規訪問者向けの終了・期限切れ・再起動後の表示は「この部屋は終了したか、存在しません」にまとめ、削除済み部屋の履歴を保存しない。

## 検証結果と残る確認

[技術スパイク](../spikes/collaboration/README.md)の7項目は合格。
Monaco 0.57.0の公開パス変更へのaliasと、Yjs 13用のYrs `small-client`設定が必要だった。
依存バージョンと設定はスパイクに固定し、実装時もこの組み合わせを基準にする。

サービス本体も実装し、Rustの5テストと独立したブラウザー2環境からの14項目のE2Eが合格した。
終了後の古い部屋ハンドルは更新を拒否し、入室時にも期限を確認する。
Windows/Edgeで通常画面を確認済み。macOS実機、全言語のインデント、実インターネット上の端末間通信は未検証。
検証の詳細と制限は[実装スライス](slices.md)に記録する。

## 判断履歴

- コード実行、MockPad内の面接履歴・フィードバック保存は初版に含めないとユーザーが決定。
- 自分だけのUndo/Redo、接続状態・自動再接続、表示名・色・選択範囲、終了・期限切れをユーザーが採用。
- 言語・タブサイズは部屋共有、1 URL 1コード、ログイン不要をユーザーが決定。
- 2026-10-24: 全員不在から24時間で削除、再起動後の復元不要、提案した作成・終了フローをユーザーが採用。
- SQLiteによる再起動後の復元案は不要になったため採用しない。
- 2026-10-24: ユーザーが実装の継続とGitHubリポジトリの作成・公開を依頼。V1〜V4の本体実装とローカル検証を実施。
